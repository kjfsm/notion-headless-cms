  - **node 版不一致が濃厚**。要対応: CI（node 24）で再実行し、環境起因か真のバグかを切り分ける

### deprecated 削除（1.0 で削除）→ ✅ 完了（本ブランチ）
- `packages/notion-orm/src/notion-adapter.ts` の `NotionCollectionCommonOptions` から
  `blocks?` / `ogp?` / `enrichers?` を**削除済み**。fallback の `getContent()` も legacy 経路を撤去し、
  `content: blocksFetcher({ ... })` 一本化。未使用 import（`BlockHandler` / `BlockEnricher` /
  `FetchBlockTreeOgpOptions`）も除去。`block-tree.ts` の `BlockEnricher` JSDoc と
  `docs/ja/migration/blocks-ogp-enrichers.md` の自動チェック節を追従更新
- changeset: `@notion-headless-cms/notion-orm` **minor**（`.changeset/remove-notion-orm-legacy-content-options.md`）
- notion-source は元々これらを転送していない（`token`/`dataSourceId`/`properties`/`collectionName`/`content` のみ）ため改修不要
- これでリポジトリ内の `@deprecated` は **0 件**（`createCms` / `CreateCmsOptions` は v2.0 で廃止済み）
- 検証: `pnpm typecheck` 24/24・`pnpm test` 24/24・biome clean（node v22.22.2）
